# Plan 3 — Chromium build pipeline (vite/copy/html/styles/icons/zip) [M0]

> Part 3 of the Sidebery → Chromium MV3 migration.
> Master plan: `docs/migrate-plan.md` — read §1 (architecture) and §6 (build items 2–6).
> Prerequisites: Plans 1–2 (staging + manifest exist).

## Goal

Produce a loadable `addon-chromium/` MV3 build: Vite config for the staged tree, thin
copy/html/styles forks, PNG icon generation, npm scripts, and a zip packaging script.
Exit criterion for milestone M0: `addon-chromium/` loads unpacked in Chrome ≥ 150
(broken features are OK at this stage).

## Ground rules

Never modify existing `src/` or `build/` files (new `build/*.chromium.*` files only;
additive `package.json` edits allowed). **Commit after each completed TODO**
(`chromium: <summary>`). Firefox `npm run build` + `npm test` must remain green.

## Context you need

- Study `build/vite.ts` first — `build/vite.chromium.ts` mirrors its structure. Also study
  `build/all.vite.js` (orchestrates styles/html/copy/scripts), `build/copy.js`
  (`handleManifest()` shows old MV2 chromium handling — do NOT reuse it, but note the
  shape), `build/html.js`, `build/styles.js`, `build/webext.run.js` (already supports
  launching a Chromium binary).
- Differences for the Chromium variant (see §1 of the master plan):
  - Source root: `.staging-chromium/src/` (run staging first).
  - `define: { IS_CHROMIUM: true }` — upstream code never references it; only overlay
    code does. (Also define whatever the upstream config defines.)
  - Entry set: same as upstream MINUS `popup.proxy`, `popup.sync`, and the
    `injections/tab-preview` bundle. The background entry keeps the same name
    (`bg/background`) but will be a service worker module.
  - Output: `addon-chromium/`.
  - Copy step: copy `manifest.json` from the staged tree verbatim (it's the Chromium one
    after overlay); skip `bg/background.html` (no background page in MV3).
  - HTML step: skip `bg/background.html`, `popup.proxy`, `popup.sync` pages.

- Firefox pipeline untouched and green.
