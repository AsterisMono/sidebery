# Plan 9 — Remove Containers (contextualIdentities) [M2]

> Part 9 of the Sidebery → Chromium MV3 migration.
> Master plan: `docs/migrate-plan.md` — read §4 intro and §4.1.
> Prerequisites: Plans 1–8 (M0+M1 complete; `IS_CHROMIUM` define and shim exist).

## Goal

Stub the container services and hide all container UI on Chromium. Chrome has no
`contextualIdentities` API. Firefox behavior must be unchanged.

## Ground rules

No upstream `src/` edits. Mechanisms, in order of preference: (1) full-file overlay in
`src.chromium/<same path>` with identical export shape; (2) small `patches/*.patch`
against the staging dir for big/churny files where a `v-if="!IS_CHROMIUM"` or small edit
suffices. `IS_CHROMIUM` is a compile-time define (true only in the Chromium build) — use
it only in overlay/patched code, never leave references that break the Firefox
typecheck. **Commit after each completed TODO** (`chromium: <summary>`).

## TODOs

   `containers.ts` — note every export. Create same-path overlays in `src.chromium/`
   with identical export shapes: empty container list, no-op CRUD returning sensible
   values, inert reactive state (keep using the same reactive primitives so consumers
   don't crash). IPC actions related to containers must return empty results, never
   throw. Commit.

   - `src/page.setup/components/settings.containers.vue` — hide the nav entry + section

   - Container rows in `popup.site-config.vue`.

   - New-tab-in-container buttons (`bar.new-tab.vue`), container marks in `tab.vue`.
   Record for each item: "self-hides with empty list" vs. "patched/overlaid" in the

3. **Dependent features sanity check.** With zero containers these must be inert —

   any unguarded call would throw — guard via overlay/patch if needed). Commit fixes.

4. **Data tolerance.** Old snapshots/configs may contain `containerId` /

5. **Verify.** `npm run build.chromium` green; Firefox `npm run build` + `npm test`
   green. Commit fixes.

## Exit criteria

- Container services stubbed; no container UI visible in the Chromium build; no code
  path can call `browser.contextualIdentities.*` or `browser.cookies.*`.
- Firefox untouched.
