## Goal

Firefox theme integration, window title preface, keybinding editing, native context
menu option, bookmark separators — and verify tolerance for misc Firefox-only tab props.

## Ground rules

No upstream `src/` edits — overlays (identical export shapes) or `patches/`. Use
`IS_CHROMIUM` in overlaid/patched code only. **Commit after each completed TODO**
(`chromium: <summary>`). Firefox build/tests stay green.
