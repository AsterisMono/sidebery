# Plan 18 — Ship: overlay-check tool, staged tests, CI, docs [M5]

> Part 18 (final) of the Sidebery → Chromium MV3 migration.
> Master plan: `docs/migrate-plan.md` — read §6 items 7–11 and §8 (fork maintenance).
> Prerequisites: Plans 1–17 (M0–M4).

## Goal

Make the fork maintainable and shippable: the overlay drift-check tool, a Chromium test
config running the suite against the staged tree, CI for both targets, and
fork-maintenance documentation. (Zip packaging `build.ext.chromium` already exists from
Plan 3 — verify it here.)

## Ground rules

No upstream `src/` edits; additive `package.json`/CI files fine. **Commit after each
completed TODO** (`chromium: <summary>`). Firefox build/tests stay green.

## TODOs

1. **`build/check-overlays.js`** (critical for fork maintenance).
   - Records the upstream git blob hash of every shadowed/patched file:
     - shadowed = every path in `src.chromium/` that also exists in `src/`;
     - patched = every file touched by `patches/*.patch` (parse the `+++`/`---`
       headers);
     - plus forked build files — maintain an explicit list of `build/*.chromium.*`
       files and which upstream file each mirrors (from the header comments added in
       Plan 3).
   - Baseline stored at `build/overlays.lock.json` (path → upstream blob hash, use
     `git hash-object` or `git rev-parse HEAD:src/...`).
   - Modes: `--update` rewrites the baseline; default mode compares current upstream
     hashes to the baseline and exits non-zero listing files whose upstream changed
     since the overlay/patch was last reviewed ("re-review these overlays").
   - Add scripts: `"check.overlays"`, `"check.overlays.update"`. Generate the initial
     baseline. Commit.

2. **Staged test config (`vitest.chromium.config.ts`).**
   - New config at repo root (or `build/`): runs the existing suite against
     `.staging-chromium/src/` (adjust the `src` alias), with `IS_CHROMIUM: true`
     defined and a minimal `chrome` global mock for the shim (setup file under
     `src.chromium/` or `build/`).
   - Include the tests written by earlier plans under `src.chromium/**/__tests__/`.
   - Script: `"test.chromium": "npm run stage.chromium && vitest run -c vitest.chromium.config.ts"`.
   - Make it pass: fix overlay-caused test failures (staged tree only). Upstream tests
     that fail *by design* on Chromium (e.g. container behaviors) may be excluded in the
     Chromium config with a comment explaining each exclusion.
   - Commit.

3. **CI workflow** (additive file, e.g. `.github/workflows/chromium.yml` — check which
   CI system the repo uses first, `ls .github/workflows/`):
   - On PRs: `npm ci`, Firefox build + `npm test`, `npm run build.chromium`,
     `npm run test.chromium`, `npm run check.overlays`, `npm run lint` if it's in the
     existing CI. Upload `addon-chromium/` zip as an artifact via
     `npm run build.ext.chromium`.
   - Commit.

4. **Packaging verification.** Run `npm run build.ext.chromium`; confirm `dist/` gets a
   zip whose root contains `manifest.json` (Chrome's "Load unpacked"/policy install
   expects the manifest at zip root — verify structure with `unzip -l`). Fix the Plan-3
   script if needed. Commit.

5. **Fork-maintenance docs — `docs/chromium-fork.md`.** Document:
   - the architecture recap (staging overlay; link `docs/migrate-plan.md`);
   - the upstream sync procedure: `git merge upstream/v5` → run `check.overlays` →
     re-review each flagged overlay/patch against upstream diff → re-run
     `test.chromium` + both builds → `check.overlays --update`;
   - how to add a new overlay/patch (rules from `src.chromium/README.md`);
   - the pinned extension ID + key handling (link `docs/chromium-id.md`);
   - install instructions (Load unpacked / enterprise policy, from the zip);
   - known degradations (condense master plan §8);
   - the manual test checklist location (`docs/plans/notes-verify-in-chrome.md`).
   - Commit.

6. **Final sweep.** Run everything: `npm run build`, `npm test`,
   `npm run build.chromium`, `npm run test.chromium`, `npm run check.overlays`,
   `npm run build.ext.chromium`. All green. `git status` clean of untracked artifacts
   (staging/output dirs ignored). Commit fixes.

## Exit criteria

- Installable zip; CI builds+tests both targets; `check-overlays` guards every
  shadowed/patched/forked file; documented upstream-sync procedure. M5 done — release
  gated only on the human manual checklist.
